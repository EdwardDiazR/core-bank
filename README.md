# 🏦 Core Bancario - Java Spring Boot

> Proyecto personal desarrollado con fines de práctica, orientado a simular la lógica central de un sistema bancario real.

---

## 💡 Descripción

Este proyecto representa la **base de un Core Bancario** construido en **Java** con **Spring Boot**, diseñado para poner a prueba y fortalecer mis conocimientos en desarrollo backend y arquitectura de software.

Incluye módulos clave como:

- 🧾 **Préstamos:** generación de tablas de amortización, pagos, cargos por mora, estatus de cuotas.
- 💰 **Cuentas:** manejo de balances, movimientos y transacciones.
- 👥 **Clientes:** registro, consulta y relación con productos financieros.
- ⚙️ **Pagos automáticos:** procesamiento de cuotas y cargos, actualización dinámica del estado del préstamo.

---

## ⚙️ Tecnologías utilizadas

| Tecnología | Uso principal |
|-------------|----------------|
| **Java 17+** | Lenguaje principal |
| **Spring Boot** | Framework backend |
| **Spring Data JPA / Hibernate** | Persistencia y ORM |
| **Oracle Database** | Base de datos relacional |
| **Lombok** | Reducción de boilerplate |
| **Maven** | Gestión de dependencias y build |


---

## 🧠 Aprendizajes y objetivos

Este proyecto me permitió:

- Aplicar **arquitectura limpia** y principios SOLID.  
- Dominar el manejo de **transacciones financieras** en entornos críticos.  
- Implementar **lógica de negocio bancaria** realista (intereses, mora, amortización).  
- Practicar **persistencia eficiente** y optimización de consultas con JPA/Hibernate.  
- Preparar la base para futuras integraciones con **Kafka** y **Keycloak** (seguridad y mensajería).
